Project Name: Kisan Rakshak AI - The Ultimate Smart Farming Ecosystem.
Design Strategy: Create a high-fidelity, mobile-responsive web application for farmers. Use a premium, modern aesthetic with Emerald Green, Deep Earth Brown, and Soft White colors. Use Tailwind CSS for a sleek UI and Lucide Icons for all navigation elements.
Key Pages & Features to Implement:
Smart Dashboard (Home):
A top section showing Live Weather and Soil Moisture %.

A dedicated page with a camera viewfinder overlay and a "Scan" button.

A list of nearby Cold Storages and Warehouses with distance and per-day pricing.

B2B Industry Marketplace:
A "Direct Connect" feed showing requirements from companies like "Lays (Potato)", "Britannia (Wheat)", etc.
An "AI Negotiator" Chatbot button that helps farmers draft a professional message to the industry for better pricing.
Kisan-Mitra Voice Assistant:
A floating, animated Mic button at the bottom right that says "Matladu Mawa".

Sustainability Card:
On the profile page, show a "Carbon Credit Score" to incentivize organic farming.
